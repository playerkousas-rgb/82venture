# 82venture · 執委會管理平台

> 一站式深資童軍自務自治服務平台
> 會議 · 財務 · 團員 · 團章，一個地方搞掂

---

## 快速開始

```bash
python3 -m http.server 8000
# 打開 http://localhost:8000
```

純靜態網站，無需安裝、無需 build。可直接放上 GitHub Pages / Netlify / Cloudflare Pages。

---

## 三個帳戶（可各自改密碼）

| 層級 | 預設帳號 | 預設密碼 | 權限重點 |
|---|---|---|---|
| 超級管理員 | `sheep` | `0728` | 全部功能；可改三個帳號嘅密碼 |
| 領袖 | `leader` | `8202` | 全部功能；可改自己同執委會密碼 |
| 執行委員會 | `exco` | `8203` | 日常操作：開會、點名、記帳、標記收款；只可改自己密碼 |

> ⚠️ **第一次正式使用前，請到「管理」頁改晒三個密碼。**

密碼規則：最少 4 個字元，可中英文數字。

## 功能模組

### 1. 會議
- 清單 / 看板兩種視圖，狀態：草稿 → 待處理 → 已確定 → 已完成
- 議程項目（含預計分鐘數，自動加總）
- 出席點名（出席／遲到／請假／缺席，可一鍵全出席）
- 會議記錄（可複製、下載 .txt）
- 決議／待辦行動：指定負責人 + 到期日，可勾選完成
- 附件登記、狀態即時變更、列印

### 2. 財務（重點）
**收支記帳** — 收入／支出、分類、收付方式、單據編號、相關團員、備註，即時結餘；依月份／類別／關鍵字篩選；匯出 CSV。

**月結報表** — 收入／支出／淨額、分類長條圖、近 6 個月趨勢圖、可列印月結表。

**收費追蹤** — 團費／活動費逐筆追；未收／逾期標示；一鍵標記已收（可自動同步加入收支記帳）；複製催繳名單（可貼上 WhatsApp）。

**活動預算**（次要）— 預算 vs 實際，自動計差異同盈虧。

### 3. 團員
- 名冊：職位、聯絡、標籤、狀態（現役／休假／舊團員）
- 個人紀錄：基本資料、出席率與逐次出席明細、收費記錄、負責嘅行動、領袖備註
- 出席率自動由已完成會議嘅點名計算
- 匯出 CSV 名冊

### 4. 進度紀錄（接駁現有系統）
- 到「進度」頁填一次網址即完成接駁（支援 Google Sheet / Notion / 任何 Web App）
- 以 **執委會** 身份開啟，唔使再登入
- 可內嵌預覽、產生 QR Code 畀團員掃
- 本系統淨係存網址，唔會讀取或修改你進度系統嘅資料

### 5. 團章（內建）
- 8 章範本條文，全部可改：增刪章節、增刪條文、改序言
- **版本記錄**：每次可「發布新版本」，自動記低版本號、日期、修改人、修訂摘要
- **輸出**：QR Code（可下載 SVG）、複製分享連結、列印／存 PDF、下載 Markdown
- 編輯權只限領袖同超管，執委只可閱讀

### 6. 管理
- 三個帳號卡片，各自改密碼／改登入帳號（受權限限制）
- 權限總表一目了然
- 匯出／匯入 JSON 備份、重設示範資料

## 技術

- 純 HTML + CSS + 原生 JS（ES Modules），零依賴、零 build
- 資料層 `assets/js/lib/store.js`：現時用 `localStorage`，接真後端只需替換此檔
- 權限 `assets/js/lib/auth.js`：集中權限矩陣
- QR Code 用 `assets/vendor/qrcode.js`（MIT，離線可用）

```
index.html
assets/
  css/main.css          設計系統 + 版面
  js/
    main.js             App Shell / 路由 / 登入
    lib/  store.js  auth.js  model.js  util.js  router.js
    views/ dashboard  meetings  finance  members  progress  constitution  admin
  vendor/ qrcode.js
```
